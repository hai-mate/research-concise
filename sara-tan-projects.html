Sara's Projects

QuantifyPolarity, a Biological Image Analysis Software (2021)

QuantifyPolarity is a software tool that automatically quantifies protein distribution and cellular properties in developing tissues. It has been widely adopted by research institutions around the world and cited in numerous peer-reviewed scientific publications. Learn more about me.

Automated Cell Segmentation and Tracking Toolkit with Machine Learning (2018)

Automated real-time cell segmentation and tracking graphical user interface (GUI) for quantitative analysis.

FibrosisQuant, Automated Quantification of Cystic Fibrosis (2016)

A robust yet user-friendly GUI for automated quantification of cystic fibrosis in human lung cell specimens.

Automated Protein Tracking and Quantification GUI (2015)

An automated GUI for tracking and quantification of the morphology and dynamics of protein over time.

MRI Brain Tumor Detection Graphical User Interface (2013)

Medical imaging computer-aided diagnostic GUI for visualization and automated detection of brain tumor in MRI scans.

Automated Temperature Controller GUI for Forced Air Warming System (2013)

Temperature controller GUI for real-time monitoring and automated control of a patient's body temperature. It continuously reads temperature data, displays the current and target temperatures, and adjusts a connected heating system accordingly.
